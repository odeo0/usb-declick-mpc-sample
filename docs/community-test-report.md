# Community test report

Copy the fields below into a GitHub issue. Include results with both settings if you tested both, and share recordings only if you have permission.

- Phone model and Android version or build
- MPC model and firmware version
- USB cable and any adapters
- Source app and audio material
- USB DeClick version and mode (`ON` or `OFF`)
- Recording duration and level, and whether playback or the USB connection changed during the test
- Audible result, including any remaining clicks or changes to musical transients
- Comparable WAV recordings and diagnostic logs, if available

See the [installation guide](../INSTALL.md) for log filenames and the [test method](testing-method.md) for a repeatable comparison.
