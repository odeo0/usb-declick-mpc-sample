# USB DeClick v0.1.0-beta.1 — установка и переключение

**Это первый публичный бета-кандидат.** Он переименован из внутренней v0.9.4; тестировщик сообщает о примерно таком же качестве, как v0.9.2. Исполняемая библиотека и механизм обработки из v0.9.4 не изменены. Длительная стабильность, использование CPU/RAM и полное качество звука пока не подтверждены.

## Перед установкой

- Используй тестовую SD, сохрани важные проекты отдельно.
- Выключи MPC и отсоедини Pixel.
- **Полностью удали предыдущую папку `autorun`**, не копируй файлы поверх старой версии USB DeClick.
- Не объединяй с SampQOL: у обоих собственный механизм изменения штатного приложения.

## Установка

1. Распакуй архив и скопируй **папку `autorun`** в корень SD.
2. Внутри `autorun/USB_DECLICK_MODE.txt` написано `ON` — **патч включён**.
3. Для **выключения** поменяй строку на `OFF`, сохрани файл и загрузись с этой SD. При `OFF` приложение MPC остаётся штатным и мод не загружается.
4. Включи MPC без Pixel. При `ON` появится чёрно-белая заставка `USB DECLICK / ON`, штатное приложение может один раз перезапуститься.
5. Подключи Pixel после появления интерфейса. Сделай короткую тестовую запись.

**Важно:** ON/OFF пока **не добавлен в экран MPC**. Это явный переключатель в текстовом файле на SD, изменение до загрузки — предпочтительный вариант. Скрипт также проверяет файл режима во время работы, но менять его на работающем устройстве следует только разработчикам, вне записи и без одновременного подключения SD для записи с другого устройства.

## Если что-то пошло не так

Полностью выключи MPC, извлеки SD с `autorun` и запусти MPC без неё — никаких изменений прошивки на внутреннем диске не было.

Пришли `autorun/usb_declick_v094.log` (внутренний диагностический ID **V094** оставлен специально, чтобы не менять исполняемую библиотеку). Для подробной диагностики перед запуском создай в `autorun` пустой файл `ENABLE_DIAGNOSTICS` (не пример `.example`); затем будет формироваться `autorun/pcmfix_runtime_v094.log` с ограниченным размером.

## Рекомендованный тест

Запиши 60 секунд того же трека на Pixel 8a при неизменном уровне, затем ещё 60 секунд с `OFF` после полного выключения/включения MPC. Не нажимай Pause/Play посреди записей. Сохрани WAV и логи отдельно, сравни субъективно и программно. Включённый алгоритм всё ещё может менять настоящие музыкальные транзиенты — тест на Samsung A06 без щелчков тоже нужен до публичной стабильной версии.

## Ресурсы

Только конкретный USB ALSA capture, 44.1 кГц/стерео/S32_LE. Не затрагивает другие источники, USB-дескрипторы и частоту. Рабочее состояние фиксированного размера; нет логирования на SD в цикле обработки PCM. **Нагрузка на реальном устройстве пока не измерена.**
